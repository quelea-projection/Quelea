quelea (2027.0) stable

  * Upgrade to Java25 and OpenJFX 25
  * New modern, clean theme
  * Universal search box (Ctrl/Cmd+K) to find songs, bible passages, images, videos, timers and notices, with a preview, and add them to the schedule
  * Printing now shows a preview of the pages first, and nothing is sent to the printer until it is approved
  * The printed schedule can include the song lyrics, with or without chords
  * Default translations now used when adding song via server
  * Support for bible book names in chapters in Zefania XML import
  * Fix UTF-8 filename issue with snap build
  * Fix issue with positions being wrong when dragging items in schedule
  * Fix memory use growing without limit (and Quelea hanging) when editing a theme with a video background
  * Theme previews that aren't on screen no longer keep playing video backgrounds in the background
  * Remote control theme thumbnails now show video backgrounds, and no longer need the theme window to be opened at startup
  * Much faster adding, editing and removing of songs with large song databases
  * Faster start-up with large song databases
  * Much faster duplicate check when importing songs
  * Fix new songs sometimes being saved twice
  * Fix changes saved just before closing Quelea sometimes being lost
  * Save notices without showing them live
  * Images, PDF pages and presentation slides that don't fill the projector screen now have black bars around them instead of see-through ones
  * Various minor bugfixes
